# 使用說明（User Guide）

## 1. 需要什麼

- EGO-XZ7 開發板、12 V 電源（J9）、MicroUSB 線接 J1（JTAG）
- Vivado（原作者使用 **2018.3**，Windows，8 GB RAM）

## 2. 燒錄步驟

1. 設定 **SW8[4:2] = 000**（JTAG 配置模式，手冊表 5）。
2. 接上 12 V 電源，撥開電源開關 S1，確認電源燈 D17 亮。
3. 用 MicroUSB 把 J1 接到電腦。
4. 依 [程式實作](04-implementation.md) 的 4.4 節建立專案並產生 bitstream。
5. Vivado → Open Hardware Manager → Open Target → Auto Connect → Program Device，可選 [實驗室原始成品](../artifacts/lab-20261111/pingpong.bit)，或自行重建的 `pingpong.bit`。
6. 燒錄完成後 D4（Done）燈亮。

> 專案只能有一個 `entity pingpong`：不要把 `archive/` 內的舊版加入專案，也不要啟用含 `seg` 的舊 XDC。

## 3. 板子上的控制

| 控制 | 位置／腳位 | 功能 |
|---|---|---|
| **SW7** | 最右邊的撥動開關 | **往上 = 運作；往下 = reset 並暫停** |
| **SW0** | 最左邊的撥動開關 | 往下 = 勻速；往上 = 隨機變速 |
| **BTNL** | 右下角十字按鍵中間那排最左 | player1 發球／回擊 |
| **BTNR** | 十字按鍵中間那排最右 | player2 發球／回擊 |
| LED0–LED7 | 板子右側，**LED0 在最下方** | 球與分數 |

> BTNL／BTNR 的實體位置是依手冊與照片推論，請以實測為準；若實測與預期不同，先核對板子方向、按鍵絲印和腳位，再記錄是否需要調整 XDC，避免直接改動已記錄的腳位。

完整實板照片留在本地交接包；公開版本省略含手寫識別標籤的照片。七段局部照片見 [驗證紀錄](05-verification.md)。

## 4. 怎麼玩

1. SW7 先往下再往上，LED0 亮：球在 player1 端，等 player1 發球。
2. player1 按 BTNL 發球，球從 LED0 往上飛向 LED7（player2 端）。
3. 球停在 LED7 的那段時間，player2 要按 BTNR 回擊，球就反向飛回。
4. 回擊失敗會讓**對手得 1 分**：
   - **太晚**：球在端點停留的時間結束了還沒按。
   - **太早**：球還在飛向你、還沒到端點時就按。（球飛離你的時候按，不算。）
5. 得分的人下一球發球，隨時可按自己的鍵開球；沒輪到發球的人按鍵無效。
6. 先得 5 分的人獲勝：勝方那半邊四顆 LED 恆亮（player1 = LED0–LED3，player2 = LED4–LED7），SW7 往下再往上重新開始。

## 5. 怎麼看 LED

**每次得分**，得分者那半邊用 **4 位元二進位**顯示他的分數，另一半邊熄滅。顯示 1 秒：前半秒亮、後半秒全暗，之後回到發球。

- player1（左）：LED0 = 最高位元 … LED3 = 最低位元
- player2（右）：LED4 = 最高位元 … LED7 = 最低位元

| 得分 | 二進位 | player1 亮 | player2 亮 |
|---:|---|---|---|
| 1 | 0001 | LED3 | LED7 |
| 2 | 0010 | LED2 | LED6 |
| 3 | 0011 | LED2、LED3 | LED6、LED7 |
| 4 | 0100 | LED1 | LED5 |
| 5 | 0101 | LED1、LED3 | LED5、LED7 |

| 畫面 | 意思 |
|---|---|
| 只亮一顆 | 球的位置 |
| 一半邊亮、另一半邊暗，約半秒後全暗 | 得分顯示 |
| 某一半邊四顆一直亮 | 遊戲結束，該方獲勝（第 5 分會先顯示一次 0101 再變成四顆恆亮） |

## 6. 球速

| SW0 | 行為 |
|---|---|
| 往下（0） | 每一步固定 250 ms |
| 往上（1） | 每次發球或回擊後，這一趟的速度隨機決定，預設為 150、250、350 或 450 ms 其中一種 |
